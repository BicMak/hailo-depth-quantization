# 2026-09-30

## 1. 원인 분석: 파싱 문제 발견
- 초기 양자화 모델의 a1이 81.94%로 낮게 나온 원인을 찾기 위해 단계별로 분석함
- ONNX → HAR FP32 변환 단계에서 이미 a1이 83.28%로 떨어져 있었음
- 원인: opset 10의 Resize(asymmetric)를 Hailo 파서가 half_pixel로 해석함
- 해결: opset 11로 변환하면서 asymmetric을 명시함 → ONNX 대 HAR FP a1 99.95%
- 단, 비트 단위로 완전히 같은 값은 아님. 평균 상대 오차 0.26% 수준으로, onnxruntime과 Hailo 에뮬레이터의 연산 차이 정도만 남음

## 2. 코드 정리
- 리팩터링 목적으로 코드를 새로 작성하고, 기존 코드는 src/legacy/로 이동함
    - common.py: 전처리, 추론, 지표
    - parse.py: 파싱. Resize 보정 포함, 노드 이름과 입력 shape을 ONNX에서 자동으로 읽음
    - quantize.py: 양자화
    - evaluate.py: 단계별 비교, median/lsq 정렬
    - visualize.py: 상위·하위 5장 그림
    - run_pipeline.sh: parse, quantize, evaluate 단계와 도움말(-h)
- 지표 추가: rel<0.1%, lsq(scale+shift) 정렬
- 버그 수정
    - adaround에 mode=train_all이 빠져서 학습 레이어가 0개였던 문제
    - legacy Accuracy_analyze.py 전처리 버그 (/255 없이 uint8 변환)
- .gitignore 추가
